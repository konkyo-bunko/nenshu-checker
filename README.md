# 2026年 年収の壁チェッカー

2026年（令和8年）の給与収入の見込みから、所得税・住民税・扶養する人の控除・社会保険の「年収の壁」を超えるかどうかと、次の壁まであと何円かの**目安**を表示する無料ツールです。

- 計算はすべてブラウザの中で行い、入力内容を送信・保存しません。Cookie・アクセス解析・広告・外部のスクリプトは使っていません
- 判定ロジックと出典（国税庁・総務省・日本年金機構・厚生労働省の公表資料）は `rules.js` にあります
- 結果は一般的な計算式による目安で、税務上の判断や申告内容、社会保険の加入・扶養の可否を示すものではありません。個別のご相談には応じていません
